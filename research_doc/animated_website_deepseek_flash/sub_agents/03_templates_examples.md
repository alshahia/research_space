### 2.3 Motion (formerly Framer Motion)

**URL:** https://motion.dev/docs  
**License:** MIT (open source core)  
**Tech:** React, JavaScript, Vue  
**How to use:** `npm install motion`

Features:
- `motion.div` component
- Layout animations (AnimatePresence)
- Scroll-driven animations
- Text animation
- Gesture-based (drag, hover, tap)
- 3D transforms
- Spring physics
- SVG animation

### 2.4 Shadcn + Animation Combos

- **Shadcn + Framer Motion** — de facto standard for animated React UI
- **Shadcn + Aceternity** — many free animated blocks
- **Shadcn + GSAP** — used in Fyrre-Magazine, agency-kit-site

**Best Vue/Nuxt starter:** nuxt-creative-base (GitHub, 47 stars) — GSAP + Lenis + WebGL + custom cursor

**Best for AI/SaaS landing:** stunning-ia-lp (MIT, Next.js 14, Framer Motion)
