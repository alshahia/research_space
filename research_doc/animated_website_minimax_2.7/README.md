## Quick Summary

### Complexity Levels

| Level | Technology | Best For |
|-------|-----------|----------|
| **Level 1** | Native CSS3 | Hover states, microinteractions, simple loops |
| **Level 2** | GSAP, Framer Motion | Scroll-driven timelines, sequenced animations |
| **Level 3** | Three.js, PixiJS | 3D spaces, WebGL, particle systems |

### Animation Types

- **Scroll-driven**: Elements animate as user scrolls
- **Hover reactions**: Interactive responses to mouse hover
- **Loading transitions**: Intro screens, preloaders
- **Page transitions**: Smooth navigation between pages
- **Text animations**: Character/word reveals, typography effects
- **3D experiences**: Canvas-based immersive environments
- **Microinteractions**: Button states, form feedback
- **Background animations**: Particles, gradients, mesh effects

### Golden Rules

**USE:**
- `transform` and `opacity` (GPU-accelerated)
- `will-change` for upcoming animations
- `cubic-bezier()` custom easing curves
- `prefers-reduced-motion` media query
- `requestAnimationFrame` for JS animations

**AVOID:**
- Animating `width`, `height`, `top`, `left`, `margin`
- Excessive `setTimeout` loops
- Overusing `will-change`
- Heavy images without optimization
- Autoplay audio without user interaction

### Performance Targets

- **60 FPS** minimum (16.67ms per frame)
- **LCP** < 2.5s (Largest Contentful Paint)
- **INP** < 200ms (Interaction to Next Paint)
- **CLS** < 0.1 (Cumulative Layout Shift)
