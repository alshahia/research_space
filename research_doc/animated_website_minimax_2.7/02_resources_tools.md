## 1. Animation Libraries

### GSAP (GreenSock Animation Platform)

| Property | Details |
|----------|---------|
| **URL** | https://gsap.com |
| **Pricing** | Free (core) / Paid (Club plugins) |
| **Key Features** | Industry-standard JavaScript animation engine; animates thousands of objects simultaneously; handles scroll-driven timelines flawlessly; automatic browser compatibility fixes; plugins include ScrollTrigger, ScrollSmoother, SplitText, Draggable, MotionPath |

### Framer Motion

| Property | Details |
|----------|---------|
| **URL** | https://www.framer.com/motion/ |
| **Pricing** | Free (open source) |
| **Key Features** | Production-ready React animation library; declarative API for complex layout transitions; gesture handling; shared layout animations; built-in motion values |

### React Spring

| Property | Details |
|----------|---------|
| **URL** | https://www.react-spring.io |
| **Pricing** | Free (open source) |
| **Key Features** | Physics-based animation library for React; natural spring animations; supports gesture-based interactions |

### Lenis (Smooth Scrolling)

| Property | Details |
|----------|---------|
| **URL** | https://lenis.studiofmt.com |
| **NPM** | https://npmjs.com/package/@studiofmt/lenis |
| **Pricing** | Free (open source) |
| **Key Features** | Lightweight smooth scrolling library; integrates perfectly with GSAP ScrollTrigger; momentum-based scrolling; works across desktop and mobile |

### CSS Animation Libraries

| Library | URL | Pricing | Key Features |
|---------|-----|---------|--------------|
| **Animate.css** | https://animate.style | Free | Drop-in CSS animations; cross-browser compatible; simple class-based usage |
| **cssanimation.io** | https://cssanimation.io | Free | Lightweight zero-JavaScript CSS animation library; 100+ pre-built effects |
| **Motion** | https://motion.dev | Free (open source) | Formerly known as Motion One; Web Animations API wrapper; hardware-accelerated; works with any framework |

### Timeline & Sequence Animation

| Library | URL | Pricing | Key Features |
|---------|-----|---------|--------------|
| **TimelineFX** | https://www.r Graphity.com | Paid | Advanced particle and visual effects; GPU accelerated |
| **Choreographer.js** | https://christinecha.github.io/choreographer.js/ | Free | Simple animation library for CSS animations |
