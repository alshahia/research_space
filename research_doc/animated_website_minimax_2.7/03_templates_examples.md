## 1. Animation & Motion Libraries

### GSAP (GreenSock Animation Platform)
- **Repository**: [greensock/GSAP](https://github.com/greensock/GSAP)
- **Stars**: 27.2k
- **Technologies**: JavaScript, Animation, Scroll, Timeline
- **What makes it notable**: Industry-standard JavaScript animation engine; animates thousands of objects simultaneously; handles scroll-driven timelines flawlessly; fixes browser compatibility bugs automatically. Essential for production-grade web animations.
- **Free/Paid**: Free (MIT) + Club plugins (paid tiers)

### Motion (Framer Motion)
- **Repository**: [motiondivision/motion](https://github.com/motiondivision/motion)
- **Stars**: 33k
- **Technologies**: TypeScript, React, Spring, Animation
- **What makes it notable**: Modern animation library for React and JavaScript; declarative API for complex layout transitions; physics-based spring animations.
- **Free/Paid**: Free (MIT)

### Anime.js
- **Repository**: [juliangarnier/anime](https://github.com/juliangarnier/anime)
- **Stars**: 71.6k
- **Technologies**: JavaScript, CSS, SVG, Canvas, Animation
- **What makes it notable**: Lightweight animation engine with a simple API; supports CSS properties, transforms, SVG, and canvas.
- **Free/Paid**: Free (MIT)

### Animate.css
- **Repository**: [animate-css/animate.css](https://github.com/animate-css/animate.css)
- **Stars**: 82.7k
- **Technologies**: CSS, Animation
- **What makes it notable**: Cross-browser library of CSS animations; drop-in easy to use; most popular CSS animation library.
- **Free/Paid**: Free (MIT)

### ScrollReveal
- **Repository**: [jlmakes/scrollreveal](https://github.com/jlmakes/scrollreveal)
- **Stars**: 22.5k
- **Technologies**: JavaScript, CSS, Scroll, Animation
- **What makes it notable**: Animate elements as they scroll into view; minimal setup; great for scroll-triggered reveals.
- **Free/Paid**: Free (MIT)

### Mo.js
- **Repository**: [mojs/mojs](https://github.com/mojs/mojs)
- **Stars**: 18.7k
- **Technologies**: JavaScript, SVG, Motion Graphics
- **What makes it notable**: The motion graphics toolbelt for the web; burst effects, swirls, shape animations; excellent for interactive storytelling.
- **Free/Paid**: Free (MIT)

### Popmotion
- **Repository**: [Popmotion/popmotion](https://github.com/Popmotion/popmotion)
- **Stars**: 20.2k
- **Technologies**: JavaScript, CSS, Physics, Animation
- **What makes it notable**: Simple animation libraries for delightful user interfaces; physics-based tweens and springs.
- **Free/Paid**: Free (MIT)

### Three.js
- **Repository**: [mrdoob/three.js](https://github.com/mrdoob/three.js)
- **Stars**: ~100k+ combined
- **Technologies**: JavaScript, WebGL, 3D, Canvas
- **What makes it notable**: Cross-browser 3D library; creates immersive 3D experiences, particle systems, shader effects; essential for high-end WebGL sites.
- **Free/Paid**: Free (MIT)

### React Three Fiber (R3F)
- **Repository**: [pmndrs/react-three-fiber](https://github.com/pmndrs/react-three-fiber)
- **Stars**: 31.6k
- **Technologies**: React, Three.js, TypeScript, WebGL
- **What makes it notable**: React renderer for Three.js; declarative 3D scenes in React; massive ecosystem (drei, postprocessing).
- **Free/Paid**: Free (MIT)

### Theatre.js
- **Repository**: [theatre-js/theatre](https://github.com/theatre-js/theatre)
- **Stars**: 12.6k
- **Technologies**: Three.js, Animation, Motion Design, DevTools
- **What makes it notable**: Motion design editor for the web; visual timeline for complex sequences; integrates with Three.js and React.
- **Free/Paid**: Free (MIT)
