# Master user task capture — T-2026-08-13-002

**Captured:** 2026-08-13
**Verbatim:** "conduct a research on how to convert this project in to top/best research project that take from user ( the topic and conduct a research on it )"

## Restated intent

User wants research on how to transform the current `research_space` project (which is currently the agents-manager multi-agent orchestration system on top of a research platform) into a **top-tier AI research product** that:

1. Accepts a **topic** as input from the user.
2. **Conducts deep research** on that topic autonomously.
3. Returns a **high-quality, best-in-class research output** (better than competitors).

This is a **discovery + strategy** task — what does "best in class" look like in 2026 in the AI research-assistant space, what does this project already have, what is the gap, and what is the conversion roadmap.

## Hub-and-spoke framing

- **Hub:** user enters a topic in the research_space web UI.
- **Spokes:** the topic is decomposed, dispatched to multiple specialist agents (research/planning/design/coder/review), each invoking live search, retrieval, code execution, citation validation, and synthesis; output is a cited, multi-format research report.

## Constraints captured

- Existing assets to inventory: `platform/` (Next.js + Drizzle + Tailwind), `research/` (existing research artifacts), `research_doc/` (eight existing research projects), `agents_manager/` (7-agent orchestrator), `share/notes/` (rich evidence bus), `share/handoffs/` (harness landscape from T-2026-08-13-001).
- Existing capabilities: multi-agent pipeline, memory system, templates, examples, decision logs.
- Goal: convert to a "top/best" research product — definitions of "top" to be researched.
