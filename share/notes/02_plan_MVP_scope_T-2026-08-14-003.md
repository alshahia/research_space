## What is IN (MVP)

The MVP is a LOCAL single-player MOBA lane loop. A feature is IN if and only if it appears below.

1. **MVP lane loop complete and fun** (DoD 1): user controls 1 hero, moves, last-hits minions, uses 4 abilities (mostly standard projectiles), versus 2-3 enemy bots that push, retreat, and dodge skillshots. (Phases P1-P7)
2. **4 allied bots** share the same brain, defer last-hits in the player lane, and complete matches with the player. (P7)
3. **Presets selectable in the pre-match menu and honored by a fresh match** (DoD 3): MatchSettings (Q3 duration), LaneLayout (Q4), VisionRuleset (Q11), DifficultyPreset (Q6). (P10)
4. **Match completes within the selected Q3 duration band** (DoD 4): MLBB 10-12 min / WildRift 15-20 / LoL 30+. (P3)
5. **Saves persist across restarts** (DoD 5): progression + mid-match checkpoint, versioned DTO, migration + round-trip tested, no BinaryFormatter anywhere. (P8)

Build-wide gates (DoD 6-9) apply to the whole build, not MVP content: 60 fps desktop / 30 fps Android floor, free stack with MIT-only borrows and clean license scan, no netcode/RL anywhere, RC builds for desktop + Android with a signed known-issues list.

## What is OUT (deferred to post-MVP backlog unless changed via the freeze rule)

- Full 5v5 and 3-lane matches (data-driven scaling path exists; content deferred per Q5)
- Second map variant (P11 optional, scope-gated, default defer)
- Extra heroes beyond the single MVP hero (hero roster is data rows, added later)
- Netcode / multiplayer / matchmaking / server sim / anti-cheat / analytics (never in scope, ADR-001)

- Paid art packs and paid middleware (Q7)
