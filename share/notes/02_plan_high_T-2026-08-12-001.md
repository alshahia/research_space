## Goal

Build the final Kotobee publishing dossier at `research_doc/kotobee_publishing/` — a 6-chapter + appendix, fully link-cited document set (7 new files + 00_README update) that turns the completed research into an actionable, bilingual (EN chapters 01–05, AR chapter 06), $0-first, multi-channel guide covering all four genre lanes, ending in an LLM/agent-ready guide with Arabic prompts.

## Non-goals

- **No re-research.** All facts come from the 3 angle files + canonical merge (`share/notes/01_*_T-2026-08-12-001*.md`). No new URLs, no re-fetching, no new claims.
- **No source code, scripts, or templates.** The dossier is documentation only (this is not a template-extraction task).
- **No full Arabic translation of chapters 01–05.** Arabic content lives exclusively in chapter 06, per user decision Q6 (hybrid). Chapter 05 carries Arabic copy-paste prompts.
- **No signup/account creation.** The 3 open research items (Author paid-tier prices, Kotobee Books ToS AI clause, "100% royalties" still active) stay marked `verify at signup` — they are not resolved during build.
- **No legal positions.** AI-copyright content is presented as checkpoints and caveats, not legal advice.

## Approach

This is a pure documentation build with zero ambiguity about facts: the three angle files are link-verified and the user locked all six decisions. The plan therefore optimizes for (a) **citation integrity** — every URL is carried verbatim from the angle files and stamped with access date 2026-08-12 in a single appendix file, so review is a cheap grep cross-check; (b) **language separation** — chapters 01–05 English-only, chapter 06 Arabic-with-English-summary, so the Arabic chapter gets its own build/review pass; and (c) **chunked delivery** — the build is split into 3 coder dispatches of 2–3 files each, one task row per file, so am-review can issue per-file verdicts.

The dossier file set renames the scaffold's provisional 01–03 names to match the master's 6-chapter contract. The scaffold's `00_README.md` planned-contents block explicitly defers the final shape to this plan, so the rename is sanctioned; the README update (P3T7) rewrites that block into the final index.

## Key decisions

1. **6-chapter structure** per the master's contract (synthesis "What the final dossier must contain" §1–7). Chapters: 01 factsheet, 02 genres, 03 start path, 04 resources, 05 LLM/agent guide, 06 Arabic deep-dive; plus README + appendix.
2. **Language split (user Q6):** 01–05 English-only; 06 Arabic-first with an English summary section; 05 embeds ≥2 Arabic copy-paste prompts. This is the hybrid the user chose.
3. **All four lanes in depth (user Q2):** the 60/40 ranking table stays, but per-lane cards for educational/children's (ranks 1–2), self-help/wellness (rank 3), fiction romance/thriller/fantasy (ranks 5–7, Amazon-export guidance), and B2B training (rank 4) are all fully built out — no thin lane.
4. **Single-sourcing:** every dossier claim maps to an angle-file section (per-file source map in the phased plan). URLs are copied verbatim; nothing invented.
5. **$0-first costing (user Q4):** start-path cost column defaults to $0 (free Author license + free Books publishing + own Stripe/PayPal); paid tiers ($150 Basic, $300 Premium, $10/mo Cloud, Library from ~$100/mo) appear only as upgrade paths.
6. **Fast lane first (user Q5):** the primary first-book plan is the 4–8-week short AI-assisted nonfiction/how-to (10–20k words); fiction is a documented 3–6-month second track.
7. **Multi-channel (user Q3):** chapter 03's channel strategy = Kotobee Books (100%-royalty interactive flagship) + KDP/Apple/Google/Kobo export + optional branded Library/Shopify; never single-channel.
8. **Verify-at-signup flags:** the 3 open items are marked in 99_appendix and cross-referenced in 01 (royalties) and 05 (ToS/AI).
9. **Chunking:** Phase 3 = 3 coder dispatches — 3A: chapters 01–03; 3B: chapters 04–05; 3C: chapter 06 + README + appendix. The Arabic chapter is its own dispatch.
