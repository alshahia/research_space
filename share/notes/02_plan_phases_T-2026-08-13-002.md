## Phase 6 — Tier 2 Research skills (activate on intent+evidence ≥ 1.5)

**Goal:** When a research task warrants more than basic webfetch, the master dispatches `am-research` with a research-skill prompt. Each skills is a markdown file under `agents_manager/research/resources/skills/` that loads on demand via the standard skill-loading pattern (matches `agents_manager/extract/SKILL.md` precedent). No new TypeScript / Python / Bash code — skills are prompt discipline + documented webfetch recipes.

**Deliverables:**
- 7 skill files under `agents_manager/research/resources/skills/`:
  - `arxiv-search.md` — recipe for `webfetch` on `http://export.arxiv.org/api/query?search_query=...&max_results=...`; XML response parsing rules; when to use it (academic / CS / physics / math).
  - `pubmed-search.md` — recipe for `webfetch` on `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=...&retmode=json`; when to use it (biomedical).

  - `citation-format.md` — prompt template that enforces `[S1]…[Sn]` inline markers + per-source reference table at the end; abstention gate (when to surface "could not verify" instead of inventing a citation).

  - `research-ar.md` — locale-aware Arabic synthesis prompts; RTL markdown conventions; matches `research_doc/kotobee_publishing/06_arabic_market_deepdive.md` style.
- `agents_manager/research/resources/skills/README.md` (the SKILLS_INDEX) — one-row-per-skill table (name, when-to-load, prompt-template path, output-format, example).

## Phase 8 — Tier 4 Multi-agent research loop + verifier + human-eval (activate on scope+evidence ≥ 2.5)

**Goal:** For multi-faceted, ambiguous, or has-known-literature research tasks, route through a multi-agent research loop modeled on the Anthropic Research pattern (LeadResearcher + subagents + CitationAgent). Reuse the existing 10-agent roster — no new agents. Add a verifier stage that flags unsupported claims and contradictions. Ship a human-eval harness with 3 hand-crafted golden topics so the user can grade output quality over time.

**Deliverables:**
- `agents_manager/research/resources/multi-agent-loop.md` — documented workflow:
  1. Master dispatches LeadResearcher (master itself) + 2–3 parallel `am-research` sub-agents (each scoped to a sub-topic).
  2. Each sub-agent writes to `share/notes/01_research_<task-id>_sub-<n>.md`.
  3. Master invokes Verifier stage: dispatches `am-review` with the verifier-prompt (see next bullet) against the consolidated draft.
  4. Verifier returns a list of unsupported claims + contradictions; master loops the sub-agents to revise.
  5. Final synthesis written to `share/notes/01_research_<task-id>.md`.
- `agents_manager/review/SKILL.md` § "Verifier mode" (appended) — a 5-line prompt template that flags (a) claims without a `[Sn]` citation, (b) claims cited but the source URL 404s, (c) contradictions between sub-agents, (d) FActScore low-confidence atomic facts.
- `agents_manager/eval/golden-tests/01-arxiv-topic/` — topic: "transformer attention variants 2024-2026"; rubric: 5 criteria × 1-5 score (citation-density, accuracy, depth, format-match, Arabic-flag-if-applicable).
- `agents_manager/eval/golden-tests/02-web-topic/` — topic: "best free research tools for solo researchers 2026"; rubric: same 5 criteria.
- `agents_manager/eval/golden-tests/03-comparison-topic/` — topic: "NotebookLM vs Perplexity Deep Research vs Claude Research — feature-by-feature"; rubric: same 5 criteria + a comparison-table-specific criterion.
- `agents_manager/eval/scripts/run-eval.sh` — bash runner: walks `agents_manager/eval/golden-tests/*/`, invokes the orchestrator on each topic, captures the output to `share/eval/<date>/<topic>/run.md`, and prints a per-topic header (rubric dimensions + empty scores for the user to fill).
- `agents_manager/eval/README.md` — explains the rubric, how to grade (paste score 1-5 per criterion), how to compare runs (JSONL delta of past scores).

**Tasks:** see `tasks/T-2026-08-13-002.md` rows starting with `P8` (P8T1–P8T7).
