  6. Asset management (icons + splash via `@capacitor/assets generate`, local fonts, images, video / audio).
  7. App metadata (`capacitor.config.ts` top-level shape, `appId` immutability, `version` + `versionCode` set in Xcode / Android Studio).
  8. Compatibility: libraries that break in a Capacitor WebView (the 8-row table from angle-conversion §9: `react-native-*`, `expo-*` SDK, `next/headers` / Server Actions, `document.cookie` on Android < 5, `navigator.locks`, Stripe Checkout with redirect, Mapbox GL JS in older WKWebView, heavy custom `<canvas>`/WebGL, IndexedDB for > 50 MB, background fetch).

  11. Plugin reference for the conversion guide (the ones angle-conversion §12 names: `@capacitor/app`, `@capacitor/browser`, `@capacitor/preferences`, `@capacitor/status-bar`, `@capacitor/splash-screen`, `@capacitor/haptics`).

### Check 2 -- Em-dash ban (UTF-8-safe byte scan)

Reads each `.md` under `capacitor-docs-2026-08-18/` as raw bytes and checks for the U+2014 byte sequence `E2 80 94`, the U+2013 sequence `E2 80 93` (en-dash), and the four smart-quote sequences (`E2 80 98`,` `E2 80 99`,` `E2 80 9C`,` `E2 80 9D`). ### Check 3 -- `[S#]` citation resolution (exact set diff)

Extracts every `[S#]` marker (numeric only, no cross-angle) from `13-sources-and-references.md`, walks every other `.md` under `capacitor-docs-2026-08-18/` and extracts every `[S#]` marker, computes the symmetric difference. FAILS if either side has a non-zero diff.
