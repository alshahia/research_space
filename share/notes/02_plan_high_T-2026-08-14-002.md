# High-Level Plan - T-2026-08-14-002

**Date:** 2026-08-14
**Sub-agent:** am-planning
**Phase:** 2 Plan

## Goal

Deliver a build-ready, milestone-based implementation plan for a local single-player 3D RTS in Unity 6.3 LTS (user vs hand-rolled AI, no network, no multiplayer), supporting 300-600 concurrent units, with economy/building/combat/fog-of-war, BOTH mid-match save/load and campaign progress, and a user-selectable 3-mode difficulty governor - grounded in the research dossier and executable by am-coder/am-design without re-reading the dossier.

## Non-goals

- No multiplayer, network, lockstep, or netcode of any kind (task constraint; `research/unity-rts-2026-08-14/06_USE_VS_AVOID.md` AVOID row 1)
- No DOTS/ECS in v1 (locked decision 1; `research/unity-rts-2026-08-14/04_NEW_TECHNIQUES.md` § DOTS/ECS)
- No RL or LLM opponent in v1 (research HIGH risk; `research/unity-rts-2026-08-14/02_OPPONENT_AI.md` § What to avoid)
- No paid AI tools (locked decision 6), no required paid assets (locked decision 3), no paid templates (research: RTS Engine delisted, `03_OPEN_SOURCE_LANDSCAPE.md` § Dead leads)
- No GOAP/HTN planners before the scripted AI works (`06_USE_VS_AVOID.md` AVOID row 13)
- No HDRP, no IMGUI at runtime, no baked CPU occlusion, no Skinned Mesh units, no GPU Resident Drawer day one (`06_USE_VS_AVOID.md` AVOID rows + `04_NEW_TECHNIQUES.md` hype filter)
- No WFC / RVO / flow fields in v1 (conditional items, only if M6 profiling demands; `04_NEW_TECHNIQUES.md` § Hype vs proven)
- No source code in this phase. The plan itself is the deliverable; am-coder executes M1-M6 in later phases.

## Approach

1. **Build from scratch, learn from the constellation.** Research verdict is unambiguous: no OSS cornerstone exists (every Unity OSS RTS is GPL, unlicensed, stale, or multiplayer-focused - `03_OPEN_SOURCE_LANDSCAPE.md` § Cornerstone verdict). The plan therefore builds from scratch, informed by MinaPecheux/UnityTutorials-RTS (MIT - the only safe reuse candidate, allowed with attribution per locked decision 8) and read-only architecture patterns from OpenRA / Warzone2100 / ATerribleKingdom.

2. **Proven architecture, proven stack.** GameObject/MonoBehaviour + ScriptableObject data + event bus (`01_RTS_CORE_ARCHITECTURE.md` § Architecture verdict), with the movement abstraction (interface + NavMeshAgent implementation) from day one so the NavMesh -> grid A* -> flow fields upgrade path is a swap, not a rewrite (`01_RTS_CORE_ARCHITECTURE.md` § 4). Unity 6.3 LTS + URP + new Input System + AI Navigation 2.0 + Cinemachine 3.1, all pinned (`04_NEW_TECHNIQUES.md` § Baseline stack).

3. **The research's 13-phase MVP roadmap (`05_BUILD_ROADMAP.md`) is bundled into 6 build milestones** with hard gates: 2A Foundation (P1-P5), 2B Economy/Building/Combat (P6-P8), 2C Fog of War + UI (P9-P10), 2D Save/Load (P11 + campaign progress per locked decision 4), 2E AI Opponent (P13 + difficulty governor per locked decisions 6-7), 2F Performance + Polish (P12). The AI is the largest milestone (3-6 weeks, research estimate) and follows the 9-system checklist with the perception layer FIRST (`02_OPPONENT_AI.md` § The single most important decision).

4. **All 9 research guardrails (`05_BUILD_ROADMAP.md` § Guardrails) are enforced as plan-level hard rules**, and every milestone carries a runnable "Done when" gate so master, coder, and reviewer agree on done without re-asking.

## Phases (one-line each)

1. **2A - Foundation** - Unity 6.3 LTS project pinned, input + camera, selection, orders + movement abstraction, unit data (research P1-P5). Gate: box-select a squad, right-click move, Shift-queue orders.
2. **2B - Economy, Building, Combat** - harvest loop, production queues, placement + NavMesh carve, combat + pooling (research P6-P8). Gate: harvest -> build -> fight loop plays end to end.
3. **2C - Fog of War + UI** - visibility grid + render-texture display, UI Toolkit HUD, uGUI world bars (research P9-P10). Gate: FoW-hidden units invisible to player AND AI.
4. **2D - Save/Load** - mid-match DTO save/load + campaign progress profile (research P11 + locked decision 4). Gate: automated save -> reload -> identical state round trip.
5. **2E - AI Opponent** - perception, build orders, economy/army managers, tactics, scouting, attack scheduler, 3-mode difficulty governor (research P13 + locked decisions 6-7). Gate: AI completes a full match vs the player.
6. **2F - Performance + Polish** - pooling/materials/instancing audit, GRD evaluation, free art integration, balance, final guardrail audit (research P12). Gate: 600 units at 60fps in a Player build, 9/9 guardrails clean.

## Risks acknowledged

- **Scope creep (HIGH):** controlled by the hard non-goals list and milestone-gate discipline (no milestone 2E begins before 2D passes).
- **Architecture fork reversal (HIGH):** movement abstraction is task P2T6 (milestone 2A); DOTS/ECS is an escape hatch only after profiling evidence (`04` § DOTS/ECS).
- **License contamination (HIGH):** learn-from-only for GPL/unlicensed repos; the only permitted code adaptation is MinaPecheux (MIT) and it requires an attribution file (`03` § License risk table).
- **Hype-vs-proven (HIGH):** proven stack only (NavMesh, JsonUtility, render-texture FoW, UI Toolkit, Cinemachine); conditional techniques (GRD, flow fields, A*) are gated behind profile data collected in 2F (`04` § Hype vs proven).
- **Version drift (MED):** all package versions pinned in manifest.json during 2A; research flagged 4+ live doc URLs 404ing and 6.2 GA unverifiable - re-verify at install (`04` § Baseline stack, § Contradictions).
- **NavMesh horde scaling (MED):** upgrade path documented in the movement contract; grid A* (A* Pathfinding Project free tier) and flow fields only if the 2F 600-unit frame test fails (`01` § 4, `05` § Estimated effort).
- **Ecosystem staleness (MED):** MinaPecheux code is Unity 2020.3 era - patterns are adapted to Unity 6 idioms, not pasted (`03` § License risk table).
- **Save-format trap (LOW/MED):** guardrails 2 + 3 (no BinaryFormatter, no Dictionary in DTOs) are hard rules enforced at review (`06` AVOID rows 3-4).

## Open assumptions

- Unity 6.3 LTS minor revision: use the latest 6000.3.x patch available at install time (research verified the 6.3 LTS line; the exact patch is unspecified).
- Package versions in the dependencies table are target pins; the exact latest compatible versions are verified at task P2T2 (docs drift per `04`).
- A* Pathfinding Project free-tier terms are verified only IF grid A* becomes necessary at the 2F profiling gate; the "Unity acquired A* Project" claim is treated as unverified (`04` § Pathfinding).
- Save library: JsonUtility (zero dependencies) is the default; switch to Newtonsoft Json.NET only if a real constraint bites during 2D (dispatch permits either).
- Game theme: generic RTS (faction-based) until the free art pack choice at 2F pins the look; art is placeholder-first per locked decision 3.
- Campaign shape: map-select progression with unlocks and win/loss tracking; no story content in v1.
