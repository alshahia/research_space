## Decision 7 - Risks + mitigations

| Risk | Mitigation |
|---|---|
| Zen free-tier rate limit / incident on the single prompt (A) | One attempt, no retry. On a bounded Zen-incident verdict ONLY, switch to approved fallback `opencode-go / deepseek-v4-flash` (same 30 s / one-attempt bounds); record which pin was used. |
| Port collision on 47831/47832/47833 | Coder checks the port is free before each run (`Get-NetTCPConnection -LocalPort <port>`); if busy, pick the next free high loopback port, update the constant at the top of the affected file + README + evidence, keep loopback. |
| CLI/SDK version skew (1.18.3 vs 1.18.18, `same-minor-patch-delta-15`) | Every example calls `client.global.health()` first and prints the version; label recorded in README + headers; NO semver compatibility claim; health failure = fail fast with sanitized error. |
| SSE stream hang / abort not honored (C) | 30 s AbortController bound before subscribe; catch rethrows only when `!signal.aborted`; finally: `clearTimeout`, `controller.abort()`, wait for iterator, then `server.close()`; bounded retry budget (sseMaxRetryAttempts 5). |
| Windows process-tree leak | `server.close()` in `finally` in all three files (SDK dispatches `taskkill /pid <pid> /T /F` on Win32 - never `process.kill` as owner); evidence records the PID-scoped cleanup + post-run port-free check. |
| Response-shape drift (usage.* / info.* / event payloads unverified) | Examples print only verified top-level shapes: `{data, error}` presence, `data.info.error.name === "StructuredOutputError"`, `parts[0].text` fallback, event `type` string defensively; never-verified fields are printed as `not-verified` markers exactly as the dossier does. |
| Prompt timeout blowout (A) | 30 s wall-clock abort on the prompt call; total run budget 60 s; failure surfaces as a bounded error, not a hang. |
| SDK module resolution failure | Exact pin in package.json; `bun install` in the folder; pre-run version check of `node_modules/@opencode-ai/sdk/package.json`. |
