- **Vite/Next.js per-framework recipes were removed from v8 docs.** `04-conversion-guide.md` reconstructs them from the v6 docs + the `declarations.ts` schema + the auto-detected `webDir` mapping. The dossier explicitly flags this as "reconstructed from v6 + auto-detect, not v8 docs first-party" so the writer (and reader) does not assume v8 ships a per-bundler guide.
- **Cordova `--platform` flag deprecated.** `02-install-and-setup.md` and `04-conversion-guide.md` use the `cap add ios` / `cap add android` form only. `cap add web` is not supported in v8 (web is the no-platform Capacitor mode).

- **Encoding lint trap.** The dossier's `findstr`-based em-dash check would be unsound on Windows (false negatives from Windows-1252 decoding; false positives from `0x97` byte matching U+2014). All text-scanning lint passes use Python stdlib reading files as raw bytes (`E2 80 94` byte sequence for em-dash); per `agents_manager/memory/global/windows-encoding-validation-trap.md`. The lint checklist in `02_plan_phases` documents the exact `py -c "<heredoc>"` command, expected stdout, and exit code per check.
- **`@capacitor/storage` is deprecated (1.2.5 stuck on legacy line).** `07-best-companion-libraries.md` uses `@capacitor/preferences` as the recommended KV store and notes the storage deprecation; `10-known-issues-and-solutions.md` documents the upgrade.
- **`@capacitor/local-llm` is experimental (Capacitor Labs).** `07-best-companion-libraries.md` lists it with the "experimental, watch-only, do not pin" note.
- **No first-party OTA story.** `08-build-and-ship.md` documents that CodePush is RN-only and the App Center service was sunset 2025-09-30; Capgo is the credible third-party option but is commercial; `11-system-prompt-for-llms.md` carries the same caveat as a hard rule.

## Banned examples (research-derived)

The dossier MUST NOT copy-paste a runnable snippet for any of these patterns; if the writer is tempted, the unsafe section in `09-do-and-dont.md` and the unsafe label in any "don't" callout explain why:

1. Pin `@capacitor/*` to `^9.0.0-alpha` -- v9 is pre-release with broken iOS framework (#8560).

5. Install the first-hit community plugin without the 4-step audit (last publish, license, permissions, maintainer) -- abandonment / AGPL / permission overreach.
6. Generate flat icon-only.png and rely on default mode for Android 12+ -- adaptive icons require foreground + background.
7. Animate `top/left/width/height/right/bottom` instead of `transform/opacity` -- layout thrash.
8. Render a >100-row list without virtualization -- frame budget lost at row 200-400 on mid-range Android.
9. Pin `@capacitor/cli@<8` while a tar `^7.5.19` security override is in `package.json` -- `extractTemplate()` fails (#8573).
10. `Haptics.vibrate({duration})` on iOS as the only tactile feedback -- iOS has no single-duration vibrator API.
