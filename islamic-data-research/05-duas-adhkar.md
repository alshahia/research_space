# 05 — Duas & Adhkar (Hisnul Muslim)

## 1. sehalhussain/Hadith-Dua-assets (GitHub) ⭐ best bundle
- **Contains:** 7 major hadith collections (sunnah.com) as SQLite + **300+ Duas & Adhkar** from Hisnul Muslim in JSON. Dua fields: `id, arabic, latin, translation, source, benefits`.
- **License:** Open-source, free to use (stated).
- **Get it:** `git clone https://github.com/sehalhussain/Hadith-Dua-assets` → `duas-adhkar-hisnul-muslim.json`.

## 2. rn0x/Adhkar-json (GitHub) ⭐ text + audio
- **Contains:** Adhkar & duas (text + audio) from Hisnul Muslim (Sa'id ibn Wahf Al-Qahtani). Categories: morning/evening, sleep, etc. Fields: `id, category, text, count, audio, filename`.
- **License:** Open (Hisnul Muslim is public domain).
- **Get it:** `git clone https://github.com/rn0x/Adhkar-json` (or download ZIP).

## 3. asellam/HisnElMuslim (GitHub)
- **Contains:** Whole HisnElMuslim book as a single JSON file (categories of adhkar).
- **License:** Open.
- **Get it:** `git clone https://github.com/asellam/HisnElMuslim`.

## 4. ThelightHub/dua-api (GitHub)
- **Contains:** 421 authentic duas (Hisnul Muslim + Quranic + special adhkar), Arabic with/without tashkeel, Bengali translations, word-by-word breakdown, 18 categories, 218 chapters. Cloudflare Workers + D1, open REST API.
- **License:** MIT (content Hisnul Muslim = public domain).
- **Get it:** `git clone https://github.com/ThelightHub/dua-api` (or use hosted API).

## 5. MohAlkurdi/athkar-api (GitHub)
- **Contains:** Doaa API from Hisnul Muslim (morning/night). JSON `{id, text, counter}`.
- **License:** GPL-3.0.
- **Get it:** `git clone https://github.com/MohAlkurdi/athkar-api`.

## 6. adiman-dev/islamic-json (GitHub)
- **Contains:** Misc Islamic JSON: Asmaul Husna, Angel names, Prophets, Adhan, Sunnah remembrance after salah, Saiyyidul Istigfar.
- **License:** No license (free to use, PR welcome).
- **Get it:** `git clone https://github.com/adiman-dev/islamic-json`.

## Also noted
- `khalid-hussain/hisnulMuslimDB` (XML/PDF/SQLite multilingual), `mohssineAboutaj/hisn-muslim-scrapping` (offline scraper w/ audio), `osamayy/azkar-db` (Azkar/Dua/Rokia dataset), `rn0x/Names_Of_Allah_Json`.

## Agent notes
- Hisnul Muslim content is widely treated as public domain → safest for commercial apps.
- For a **reminder agent**, use `rn0x/Adhkar-json` (has `count` for repetition + audio).
