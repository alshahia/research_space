# Memory — 01 Medusa 2 backend

Quick reference for working on `apps/backend/` (Medusa 2.x commerce server). Last verified: 2026-08-14. Source: https://docs.medusajs.com/

## What it is

Medusa 2 is a Node.js commerce server. It's NOT a CMS, NOT a hosted SaaS — it's a self-hostable commerce engine. Database is Postgres (default) or MySQL. Cache/queue/pubsub is Redis (optional in dev, required in prod).

## Medusa 2 vs Medusa 1 (upgrade cheat sheet)

Medusa 2 is a full rewrite. Key differences:

| Old (v1) | New (v2) |
|---|---|
| `src/medusa-config.js` (JS or TS) | `medusa-config.ts` (TS only) |
| `src/api/index.ts` with `MEDUSA_API_ROUTES` array | `src/api/<path>/route.ts` with HTTP-verb-named file exports |
| `src/extensions/` (extension modules) | `src/links/` (link modules — much simpler) |
| Custom service files under `src/services/` | Modules registered via `defineModule` + `moduleService` |
| `medusa new --seed` | `medusa db:create && medusa db:migrate && medusa db:seed` |
| `medusa start` (default 9000) | `medusa develop` (dev) / `medusa start` (prod) |
| TypeORM-based entities | MikroORM-based entities |

## Defining an API route (Medusa 2 pattern)

```ts
// src/api/store/products/route.ts
import type { MedusaRequest, MedusaResponse } from "@medusajs/medusa"

export async function GET(req: MedusaRequest, res: MedusaResponse) {
  const limit = Number(req.query.limit ?? 6)
  const offset = Number(req.query.offset ?? 0)
  const productModule = req.scope.resolve("productModuleService")
  const [products, count] = await productModule.listAndCount(
    {}, { skip: offset, take: limit }
  )
  res.json({ products, count })
}
```

The route file is auto-registered by the framework — no manual registration needed.

## Defining a link (Medusa 2 pattern)

```ts
// src/links/product-category.ts
import { defineLink } from "@medusajs/framework/utils"
import ProductModule from "@medusajs/medusa/product"
import CategoryModule from "@medusajs/medusa/category"

export default defineLink(
  ProductModule.linkable.product,
  CategoryModule.linkable.category
)
```

This wires product ↔ category as a many-to-many via `product_category_product` join table, auto-generated on first migration.

## CLI commands (cheat sheet)

| Command | What |
|---|---|
| `medusa db:create` | create the Postgres DB from `DATABASE_URL` |
| `medusa db:generate <name>` | generate a new migration (MikroORM) |
| `medusa db:migrate` | apply pending migrations |
| `medusa db:seed` | run `src/scripts/seed.ts` |
| `medusa develop` | dev server with watch mode |
| `medusa start` | prod server (post-`medusa build`) |
| `medusa build` | compile to `.medusa/server` + `.medusa/admin` |
| `medusa user --email ... --password ...` | create admin user |
| `medusa --version` | CLI version |

## Common gotchas

- **MikroORM vs TypeORM.** If you see TypeORM-style entities from Medusa 1 docs, ignore them. MikroORM uses `@Entity()` + `@Property()` decorators, generates to `node_modules/.cache/medusa/migrations/`.
- **Redis optional in dev, required in prod.** `medusa develop` will start without Redis but log a warning.
- **CORS is per-route.** Medusa's middleware doesn't enforce CORS globally — set `STORE_CORS` in `.env` or wire `src/api/middlewares.ts`.
- **`medusa build` writes to `.medusa/`** — gitignore this.
- **`links/` is not `extensions/`.** Medusa 1's `src/extensions/` is gone.
- **Strict TS settings.** Medusa's framework relies on TS path aliases; our `tsconfig.json` matches the framework's expectations.

## What this scaffold does NOT cover

- Custom modules (`src/modules/`). Defer to maintainer; we ship the framework's product/category/order modules untouched.
- Custom entities (override `Product` to add fields). Defer.
- Subscribers (`src/subscribers/order-paid.ts` for `checkout.session.completed`). Referenced in `tier2-storefront` `SPEC.md` `## Deferred items`.

## Tests on Windows

- `pg-mem` (`^3.0.5`) is in `optionalDependencies`. It mocks Postgres in-process; tests don't need a real DB.
- `medusa-js` is mocked in `tests/smoke-backend.test.ts`. Real HTTP calls to a running Medusa are out of scope.
